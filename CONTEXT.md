# Portfolio

A single-page developer portfolio for Jethro, targeting recruiters hiring for junior developer, SOC analyst, IT support, and QA roles, and developers reviewing the work.

## Language

**Section**:
A top-level content division of the single scrolling page. Named Sections are: Hero Section, Experience Section, Projects Section, Skills Section, Footer Section.
_Avoid_: page section, block, panel, region

**Project Card**:
An item in the Projects Section containing a screenshot or placeholder, project title, one-sentence description, tech tags, and a single action button.
_Avoid_: card, project item, project tile

**Skill Group Card**:
An item in the Skills Section containing a category title, one descriptor sentence, and a list of tech icons with text labels. The three cards are: Frontend, Backend, and Security and Testing.
_Avoid_: card, skill card, skills item

**Tab**:
A selectable view within the Experience Section toggle. Named Tabs are: Experience Tab and Education Tab.
_Avoid_: panel, view, pane

**Experience Entry**:
An individual item within the Experience Tab, showing organisation, role title, dates, and bullet points.
_Avoid_: experience item, timeline item, role entry

**Education Entry**:
An individual item within the Education Tab, showing institution or certification name, qualification, and date.
_Avoid_: education item, qualification entry, cert entry

**Project Card Action**:
The single clickable action on a Project Card. Variants are App Store Button (links to an App Store listing) and GitHub Button (links to a GitHub repository). Each Project Card has exactly one.
_Avoid_: live button, CTA, link button

**Tech Tag**:
A small pill label on a Project Card naming a technology used in that project.
_Avoid_: tag, badge, chip, label

**Tech Icon**:
An icon paired with a text label in a Skill Group Card representing a specific technology or tool.
_Avoid_: skill icon, icon label, tech badge

**Nav Bar**:
The horizontal navigation component fixed at the top of the page on desktop, containing anchor links to each Section.
_Avoid_: header, top nav, navigation bar, navbar

**Bottom Nav**:
The sticky navigation component fixed at the bottom of the screen on mobile, containing anchor links to each Section.
_Avoid_: footer nav, mobile nav, sticky nav, tab bar

**Theme**:
The active visual mode of the site. Two values: Dark Theme and Light Theme. Dark Theme is the default.
_Avoid_: mode, colour scheme, appearance

**Theme Toggle**:
The interactive control that switches between Dark Theme and Light Theme.
_Avoid_: mode toggle, dark mode switch, colour toggle

**Social Link**:
One of three icon-only contact touchpoints: LinkedIn, GitHub, and Email. Appears in the Hero Section and the Footer. Each renders as an icon with no visible label.
_Avoid_: social icon, contact link, icon button

**Screenshot Placeholder**:
The temporary visual shown at the top of a Project Card before a real screenshot asset is supplied.
_Avoid_: placeholder, empty state, placeholder image

**Nav Link**:
An individual clickable item in the Nav Bar or Bottom Nav that scrolls the page to a named Section.
_Avoid_: anchor link, nav item, menu link

**Tagline**:
The single bold statement displayed beneath the display name in the Hero Section. Current value: "I build things that just work."
_Avoid_: subtitle, strapline, hero statement, bold statement
