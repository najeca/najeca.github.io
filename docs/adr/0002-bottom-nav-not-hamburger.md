# Bottom Nav on mobile instead of hamburger menu

The original brief specified a hamburger menu on mobile that would open an overlay combining nav links and social links. This was replaced with a Bottom Nav — a sticky bar fixed to the bottom of the screen containing the same Nav Links as the desktop Nav Bar.

A hamburger on a single scrolling page adds a tap to open, an overlay to read, a link to tap, and a close gesture — all to save one or two swipes of scrolling. The friction exceeds the benefit. A Bottom Nav is always visible, requires no interaction to access, and matches the app-like navigation pattern that suits a single-page site. Social links remain in the Hero Section and Footer, which are both reachable by scrolling.
